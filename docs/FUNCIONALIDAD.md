# Funcionalidad

- Cliente → Proyecto → Línea/Máquina → Límite → cruces Peligro × Tarea → RAMS.
- Cada cruce queda marcado Y o N.
- Solo un cruce Y habilita la carga de los cuatro factores para tres escenarios.
- Al pasar un cruce a N se elimina su evaluación RAMS asociada.
- Datos locales con exportación/importación JSON y exportación CSV.
- Interfaz adaptable, identidad visual AVEC y operación offline después de la primera visita con conexión.

Los catálogos de peligros y tareas se han dejado como valores iniciales editables. No se debe asumir que representan literalmente las listas del Excel si el libro fuente no se ha validado en esta versión.
